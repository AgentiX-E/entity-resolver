# @agentix-e/entity-resolver

**Entity Resolution for Node.js and Browser**

Stateless pure-computation engine with WASM acceleration. One import, all packages.

```typescript
import { dedupe, linkRecords, autoConfigure } from '@agentix-e/entity-resolver';
```

## Packages Included

| Package | Weight |
|---------|--------|
| `entity-resolver-core` | Algorithm engine, types, interfaces |
| `entity-resolver-node` | DuckDB, PostgreSQL, file I/O |
| `entity-resolver-browser` | DuckDB WASM, IndexedDB |
| `entity-resolver-server` | REST + MCP API |
| `entity-resolver-cli` | Command-line tool |
| `entity-resolver-visual` | Diagnostic components |
